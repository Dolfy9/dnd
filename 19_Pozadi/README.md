# Pozadí

Vlastní (homebrew) obsah typu `pozadi` pro pravidla D&D 2024. Soubory mají YAML hlavičku `pozadi:` podle šablony v `_Sablony/` a jsou označené `vlastni: true`.

Strukturovaná data (např. `efekty` u featů/předmětů) používá engine postav – viz `web/assets/efekty2024.json` pro oficiální příklady zápisu.
