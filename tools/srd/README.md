# Data SRD 5.2.1 (CC-BY 4.0)

Skripty, které přegenerují `web/assets/srd/*.json`:
- `open5e.py` – bestiář (Open5e API, dokument `srd-2024`)
- `open5e_items.py` – předměty a výbava (Open5e API)
- `glosar.py` – glosář pravidel (vstup `glosar_raw.txt` = `pdftotext -f 176 -l 208 SRD_CC_v5.2.1.pdf`)
- `convert.py` – featy a původy z `foundryvtt/dnd5e` `packs/_source` (sparse clone do `~/srd/foundry`)
